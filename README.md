# Farmer Buyer Marketplace

A Flutter marketplace connecting farmers with buyers.

## Getting started

1. Install the Flutter SDK and add it to `PATH`.
2. Run `flutter pub get`.
3. Configure Firebase for the target platforms.
4. Run the app with `flutter run`.

## Project structure

- `lib/core`: shared constants and application configuration
- `lib/models`: application data models
- `lib/services`: Firebase and persistence services
- `lib/screens`: application screens
- `lib/widgets`: reusable UI components
